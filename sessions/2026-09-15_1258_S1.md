### Долги миграции и панели (честно)
- **Looks, текстуры, устройства и переходы не переехали в `library/`** — остались в `engine/`, каталог панели собирается из engine. Решение и причина — в DECISIONS.
- **`trim` из media.json движок не читает.** Ползунки обрезки пишут `media.json → trim`, а в бите время по-прежнему задают `stage.in/out`. Нужно либо брать trim по умолчанию, либо кнопку «применить к битам».
- **Перерендер бита — полная пересборка** (заменить сегмент MP4 движок не умеет; пометка в панели). Переозвучка проверена до подтверждения: расход, остаток и отказ у Kokoro. Настоящую переозвучку не запускал, чтобы не тратить символы.
- **Формы битов:** regions, hold, markers, route, data, target — поля JSON с проверкой, а не визуальный редактор. Внизу карточки — весь бит JSON-ом.
- **Этапы режиссёра угадываются по командам** (research / media / project / build), это приближение.
- **Режиссёр запускается с `--allowedTools Bash,…` и `acceptEdits`** — любые команды bash в корне репозитория без подтверждения.
- **Drag-and-drop не проверялся мышью в браузере.** Загрузка проверена через тот же API (POST файла). Скриншоты — headless Chrome.
