# Архив отчётов

Отчёты старше недели переезжают сюда: в `sessions/` остаются только свежие, и следующая сессия читает **один** последний отчёт (CLAUDE.md, «Прогресс сессии»).

Переносить руками в конце сессии: `git mv sessions/<файл> sessions/archive/`. Ролики, MP4 и рендеры в `sessions/` не кладутся — им место в `projects/<id>/renders/`.
