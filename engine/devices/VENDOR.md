# Вендоренные компоненты реестра HyperFrames

Установлены `hyperframes add <name> --no-clipboard` (CLI 0.8.36) в песочнице и скопированы как есть в `vendor/<name>/<name>.html`. Хэш из `hyperframes.lock.json` совпадает с sha256 файла — в таблице первые 16 символов. Отдельной версии у компонентов реестра нет: версия — CLI + хэш. Шрифт Caveat (`assets/fonts/Caveat-700-latin.woff2`) ставится вместе с hw-*, но обёртки подписывают шрифтами стиля (Inter / Cormorant), поэтому он не вендорен. CDN-тег gsap 3.14.2 из self-preview каждого компонента не переносится: gsap 3.14.2 лежит в `engine/assets/vendor/gsap.min.js`.

Общее для всех обёрток: цвета — только токены палитры через `api.color` (белая маска-клон — `C.white`, при отсутствии `C.text`), тени — `rgba(RGB.night, …)`, шрифты и размеры — из стиля; Math.random заменён сидом `api.rand()` для выбора позы шума; все анимации — property-твины на `api.tl` от `dev.at`, базовый `tl.set` в 0 перед fromTo.

## Не вендорены (свои аналоги в stage)

| Компонент | Где у нас | Почему свой |
|---|---|---|
| before-after-wipe | stage `split` (`engine/src/stage.ts`, `engine/stage/runtime.js`) | шторка — это stage, а не устройство: два медиа со своими клипами, стоп-кадрами и обработками; компонент — слоты-обёртки поверх готового контента. У нас clip-path `inset()` на обёртке `b`, разделитель по краю, подписи BEFORE/AFTER на подложке |
| svg-stroke-trace | stage `map` → `route` | маршрут рисуется тем же dashoffset, путь строится из точек в % (сглаживание Катмулл-Ром), без дрейфа на удержании |
| offset-path-traveler | stage `map` → `route.traveler` | бегунок — `offset-path: path(…)` и твин `offsetDistance` 0 → 100 %, без поворота по касательной |
