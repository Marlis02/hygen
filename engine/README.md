# engine

Только код движка: CLI и конвейер (`src/`), шаги на Python (`py/`), рантайм stage (`stage/`), копии скриптов навыков (`vendor/`). Всё, из чего собирается ролик (looks, стили, текстуры, устройства, субтитры, переходы, motion, сцены, арки, intents, ассеты, музыка), — в [library/](../library/).

Строится по [ROADMAP.md](../ROADMAP.md), начиная с D1. Правила работы — в [CLAUDE.md](../CLAUDE.md).
