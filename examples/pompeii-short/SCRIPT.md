# SCRIPT — pompeii-short

**Voice:** Silero TTS `v5_ru`, диктор `eugene` (мужской, низкий; медианная F0 ≈ 82 Гц) — локальный синтез, 48 kHz
**Voice settings:** SSML `prosody rate="medium" pitch="low"` · ручные ударения на рискованных словах · паузы 320 мс между предложениями, 130 мс в перечислении · каждая реплика −16.2 LUFS (моно; в стерео-миксе ≈ −13 LUFS), true peak ≤ −2.5 dBTP через прозрачный look-ahead лимитер, без компрессии
**Voice direction:** Спокойно, низко, без нажима — голос трейлера документалки. Тяжёлые факты не драматизировать, не повышать тон.
**VO_MODE:** verbatim — текст пользователя дословно, озвучен целиком.
**Почему не `npx hyperframes tts`:** в CLI это Kokoro-82M, у него нет русского: `--lang ru` отклоняется («Must be one of: en-us, en-gb, es, fr-fr, hi, it, pt-br, ja, zh»), а без флага фраза синтезируется англоязычной фонетикой в нечитаемые 13 с. HeyGen-голоса требуют входа в аккаунт. Поэтому голос — локальный русский Silero, генератор: `scripts/voice/make_voice.py`.
