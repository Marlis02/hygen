# Решения

Что решили и почему. Новые записи — сверху.

## 15.09.2026 — S1 «Studio и хранилище проектов»

- **Проект — папка `projects/<id>/`, ролик и лицензии — два файла в её корне.** `project.json` = бывший video.json + `status` (draft · built · verified · published), `proof`, `concept` (раздел Concept research.md) и `sees` у битов («что видит зритель» из раздела Beats); research.md остаётся приложением. `media.json` — все лицензии одним файлом (ключ — имя файла: role, title, source, author, license, url, added, notes, crop, trim), в `media/` только файлы. Файл без полной записи и запись без файла — ошибка build (до голоса) и новая проверка `verify → media`. publish/ переехал в `renders/publish/`. Движок читает только project.json: video.json нигде не поддерживается, миграция одна — `npm run migrate`.
- **Proof-проекты — в том же `projects/` с `"proof": true`, а не в `projects/_proof/`.** Одна плоская папка: команды принимают id, уникальность и бюджет обходят один список, панель фильтрует по флагу. `videos/_proof/voices` (не проект) → `library/voices`, `videos/_compare` → `sessions/compare-d3.5`.
- **Лицензия ищется по месту файла, а не по соседнему json:** `projects/<id>/…` → `media.json` проекта (папка внутри projects/ считается проектом и без project.json — режиссёр качает медиа раньше, чем пишет project.json), `library/music/…` → `music.json`, `engine/assets/…` → `engine/assets/media.json` (силуэты карт и картина Волера). license.json не осталось нигде.
- **Музыка — библиотека, в проекте только ссылка.** `library/music/<трек>` + `music.json` (bpm, mood, looks) + `beats/<трек>.beats.json` с sha файла — сетка считается при добавлении трека и пересчитывается только при смене файла. `project.json → music: {track, gain, duck, in, out}`; `volume` — старое имя `gain`. Треки не из библиотеки (свой wav проекта) по-прежнему кэшируются в `.cache/beats`.
- **Looks, текстуры, устройства, переходы остаются в `engine/`, `library/` — только музыка, превью и голоса.** ROADMAP S1 перечислял их в library/, но движок и 91 элемент грузятся из engine/ по путям, которые знают навык, CONTRACT и vendor-хэши; перенос ничего не даёт панели (каталог собирает `engine/src/library.ts`), а риск регрессии Помпей — есть. Промпт S1 требовал в library/ только музыку.
- **`hygen.config.json` — всё не секретное, `.env` — только ELEVENLABS_API_KEY и PEXELS_API_KEY.** Миграция перенесла VOICE_PROVIDER, ELEVENLABS_VOICE_ID, ELEVENLABS_BUDGET_CHARS в конфиг и удалила их из .env (значения не печатались). Порядок голоса: `--voice` > project.json > переменная окружения VOICE_PROVIDER (разовый запуск) > конфиг. Битрейт мастеринга (`X264`) и целевая длина Short — тоже из конфига; doctor проверяет конфиг и предупреждает о не-секретах в .env.
- **Снимок истории — только если project.json или media.json изменились** (`history/<дата>/snapshot.json` с digest): десять пересборок без правок оставляют один снимок. Снимок делают build, откат, удаление бита и «применить из библиотеки»; старые архивы D6 (history/2026-09-14 с video.json → project.json) остались как есть.
- **Эталон Помпей обновлён один раз из-за разметки whisper (долг D7).** Сборка из `projects/pompeii-en`: лист против сборки до миграции 12/12, против эталона HEAD 11/12 — только полоса субтитров r1c3; в SRT три фразы сдвинуты ≤ 0,5 с (17,6–23,7 с). Новый эталон — лист и `renders/publish/subtitles.srt` этой сборки; дальше регрессия снова 12/12 целиком.
- **Панель — Node без фреймворков, страница — TypeScript без сборки.** `studio/server.ts` снимает типы `module.stripTypeScriptTypes` при отдаче `.ts` (как движок запускается без сборки), интерфейс — свой `h()` и хэш-роутер: зависимостей ноль, сеть не нужна, слушает только 127.0.0.1. Все строки — `studio/i18n/ru.json`, серверные сообщения движка остаются русскими. Долгие команды — дочерние процессы (`studio/jobs.ts`), этапы сборки — из строк `▸` build.ts. Файлы страница читает только из projects/, library/, шрифтов и .preview/ — `.env` не отдаётся, секреты приходят как «есть/нет».
- **Формы битов — из определений движка, списков в панели нет:** параметры устройств — device.json (+ text.schema.json у текстовых), сцен — scene.json, поля бита и media — `$defs` schema.json, intents, looks, текстуры, переходы, пресеты субтитров — из папок. Что формой не выразить (regions, hold, markers, data) — поле JSON с проверкой; весь бит можно править JSON-ом внизу карточки.
- **«Перерендер бита» = полная пересборка с пометкой.** HyperFrames 0.8.36 рендерит композицию целиком (нет диапазона кадров), мастеринг перекодирует весь файл и нормализует громкость всего ролика — вклеить сегмент без шва по звуку и GOP нельзя. Голос, звук и кадры берутся из кэша, 4–6 минут. Переозвучка бита — дубль ElevenLabs этого бита уходит в history/, показывается расход символов и остаток бюджета до подтверждения; у Kokoro дубль детерминирован — переозвучка отклоняется.
- **Превью библиотеки — `npm run library:previews`, 540×960, 3 с, кэш по хэшу файлов элемента** (субагент блока 4): `scene … --render <mp4> --name <папка> --no-sheet` (общий флаг, им же панель делает превью бита). MP4 превью в git не идут (8,9 МБ, пересобираются по кэшу), `library/previews/index.json` — идёт.
- **Режиссёр из панели — `claude -p "/short <id>" --output-format stream-json --permission-mode acceptEdits --allowedTools Bash,Read,Write,Edit,…`.** Проверка `claude -p` с подпиской прошла (ответ за 1,8 с). Навык v3.3 читает `projects/<id>/brief.json` (тема, look или null, голос, длина, пожелания) и пишет `sees` у битов и `--role` при скачивании; если claude недоступен, панель показывает команду и ждёт project.json.

## 15.09.2026 — D7 «закрытие недели»

- **Кэш дублей ElevenLabs — в папке ролика и в git.** `videos/<id>/voice/<sha(provider, voiceId, model, text)>/` (take.wav 24 кГц 16 бит, alignment.json, meta.json) и `videos/<id>/voice/usage.jsonl`: голос едет вместе с проектом, пересборка на другой машине не тратит символов (D6 на машине №2 без кэша ушла на Kokoro). `.cache/voice/elevenlabs` — только превью голосов и отметки сброса бюджета. Дубль из старого глобального кэша переносится при сборке сам или командой `npm run voice -- --migrate` (по label `<id>/<бит>`), его запись расхода переезжает с тем же `at`.
- **Бюджет ElevenLabs — одна шкала по времени из `.cache` и всех проектов,** запись с одинаковыми `at` и label считается один раз. Бюджет 3 000 — на сессию: 1 248 символов D5 (превью, proof titanic-v2, Halifax) остались до отметки сброса D7.
- **Голос роликов — `ELEVENLABS_VOICE_ID` из `.env` (Michael C. Vincent, выбор пользователя в D5),** в video.json только `"voice": {"provider": "elevenlabs"}`: один голос у всех роликов меняется одной строкой `.env`. Halifax в D5 записан этим голосом — пересборка из кэша, 0 символов.
- **Treatment `duotone` — две краски look с потолком светлоты 72 %.** Тени — night, света — text с четвертью hero, не ярче 72 %: белая бумага карты и небо фото не выпадают из тёмного мира, тёмная цифра поверх карты («2/3» цветом night) остаётся читаемой. Яркие насыщенные точки (огни ёлки, лампы) не гасятся, а становятся пятнами цвета cold — акцент в ч/б кадре. Видео — та же тоновая карта ffmpeg без пятен.
- **type-swap раскладывает постоянную часть на 1–3 строки,** если так кегль всего хука растёт больше чем на 10 %: одна строка «THE LOUDEST SOUND» упиралась в ширину и давала 69 px при `size: xl`. Строки и слот — по ширине безопасной зоны (x 70–1010), слот не прыгает.
- **extrude заполняет ширину, а не шкалу кеглей:** кегль — по 90 % безопасной ширины, шкала только ограничивает короткое слово; шаг глубины 4,5 % кегля.
- **behind-subject ставит слово по фигуре, измеренной сборкой** (`media_stage.py extent`: полосы вырезки в пикселях кадра с тем же fit и focus). Середина слова уходит за фигуру, первая и последняя буквы — в чистом небе с запасом на дрейф; места нет — кегль меньше, слово не режется. Фигура во всю ширину кадра (затылок крупным планом при `cover`) места не оставляет — у proof typo 11-look-up stage `fit: contain`.
- **Great Fire 01 — не обводка абзаца, а push-in к строке:** `crop` от всей таблички к «SEPTEMBER 1666 BEGAN» (центр кадра держит строку на одной высоте) и `focus.spotlight dim` полосой строки; подпись PUDDING LANE, 1666 остаётся — она объясняет, что за табличка.
- **Хроника Titanic остаётся British Pathé.** На Commons по «Titanic 1912 film» — только два файла той же хроники Pathé, по «Southampton Queenstown 1912» — ничего; Pexels даёт только реплику корабля. Хроника кадрирована без логотипа (D5), в `publish/description.md` — строка об источнике; риск заявки Content ID остаётся (D5).
- **Эталон Помпей не переписывается из-за субтитров.** Регрессия D7: выше полосы субтитров 12/12, в полосе у 03-eruption другое слово — whisper заново разметил слова того же кэшированного голоса, фразы SRT сдвинулись ≤ 0,5 с. Файлы эталона возвращены из git.

## 14.09.2026, ночь — D6 «текстовая система, доводка к публикации, пересказ»

- **Субтитры — устройство `text.caption`, а не скин captions.mjs.** Одна подкомпозиция `compositions/captions.html` на весь ролик (`engine/src/captions.ts` → `engine/devices/text.caption/device.js`): группы word | phrase | line из таймингов голоса, стиль бита — `look.captions` ← `video.json captions` ← `caption` бита, пресет — модуль `HygenCaptions.define` с флагами `owns` (фон, активное слово, вход). Скин с плашкой и линией сверху из сборки убран; хост `el-captions` по-прежнему ставит assemble-index — по наличию файла. Субтитры не входят в `devices` бита и в плотность грамматики: это слой ролика.
- **Контраст под субтитрами меряется до рендера.** Слой субтитров пишется пустым, `hyperframes snapshot` снимает 2 момента каждого бита без подложки, `engine/py/caption_contrast.py` сравнивает цвет текста с 90-м перцентилем яркости под светлым текстом (10-м — под тёмным); ниже 4,5:1 — wash (bottom, top, follow-camera) или blur (center, near-target) и предупреждение. `verify → text` читает план сборки, MP4 заново не меряет: слово субтитра из кадра не отделить от фона.
- **Общая текстовая схема — `engine/devices/text.schema.json`**, устройство включает её полем `text` в device.json (шкала кеглей и свои умолчания); свои enum-поля устройства сохраняют старые значения (`size: headline | title | label`, `large | medium`), поэтому старые video.json собираются без правок. Цвет `secondary` = `cold` = цвет второго тона look.
- **`sync` — у каждого устройства и у бита.** music — ближайший бит сетки трека; both — бит, если он ≤ 100 мс от слова, иначе слово; ритм внутри устройства (строки stack, ряды marquee, волна weight-morph) шагает по битам. Два ритма в бите — ошибка грамматики. Субтитры всегда идут по голосу.
- **Сетка битов — свой `engine/py/beats.py` на numpy/scipy**, кэш `.cache/beats/<sha трека>.json`: librosa в окружении нет (numba и llvmlite ради одной функции), `beat-analyzer` пакета hyperframes — браузерный bpm-detective без сильных долей. Петли подложки учитываются так же, как склеивает `music_bed.py` (кроссфейд 2 с). Тестовый трек `test-beat-100` — процедурный и длиннее Short (72 с): подложка не склеивается, сетка целая.
- **`text.kinetic` — одно устройство с 12 режимами, а не 12 устройств:** общий текст, шкала, позиция, `sync`; грамматика — устройство доминирует, соседей не больше одного, в ролике не больше 2 битов (кроме `typography.kinetic`). Вариативный шрифт — Archivo (OFL, wght 100–900 × wdth 62–125 %), `@font-face` только в кадрах с weight-morph.
- **behind-subject режет фигуру из того же обработанного кадра stage**, поэтому у stage запрещены crop, pan и zoom — иначе вырезка съезжает с фото. Камера движка двигает хост целиком и совпадение не ломает.
- **Помпеи с новыми субтитрами — новый эталон (обновлён один раз за D6).** Субтитры plain по слову, без плашки и линии; контраст под ними от 10,26:1, подложки движку не понадобились. Лист `videos/pompeii-en/renders/pompeii-en.contact.jpg` сборки 23:11: с эталоном D5 совпадают 12 плиток из 12 выше полосы субтитров (среднее 1,08–1,89), целиком — 2 из 12 (разошлись только субтитры). Рендер 103,4 с против 108,0 с базы на HEAD.
- **Непрерывная кинетика не сравнивается со снимком.** marquee и weight-morph движутся в любой момент бита: кадр MP4 и снимок композиции в момент settle расходятся на долю кадра (124,5 и 50,7 при пороге 32), как у играющего видео. Такие биты помечаются в плане проверки флагом `video`; остальные режимы text.kinetic устаиваются и сравниваются.
- **Подложка текста — против цвета букв, а не всегда `night`.** На светлом look `night` — бумага: wash из бумаги под светлым неоном сделал его нечитаемым. Тень и плашка берутся тёмные для светлых букв и светлые для тёмных; пресет, который сам красит буквы (neon-glow, neon-accent, texture, gradient-fill), объявляет `ink: "light"` — по нему же меряется контраст до рендера. Пресет со своей плашкой (pill-karaoke, blend-difference, camera-follow) отвечает за контраст сам: низкий контраст — предупреждение, не ошибка.
- **Ролики к выкладке просят ElevenLabs, а на машине без ключа собираются на Kokoro.** Great Fire, Halifax, Titanic и Krakatoa в video.json — `voice.provider: elevenlabs` с запасным голосом Kokoro (`voice.voice`: bm_george для Лондона, am_michael для остальных); на этой машине `.env` без ключа, поэтому MP4 сессии — черновой голос. Финальный голос — пересборка на машине с ключом: тайминги слов из API сдвинут устройства и субтитры сами, дубли уйдут в кэш. Помпеи остаются эталоном на Kokoro.
- **Бюджет ElevenLabs — на реплику, а не на ролик.** Ошибка API по-прежнему откатывает весь ролик на Kokoro (D5), а кончившийся бюджет — только реплики, которым не хватило символов, с предупреждением «смешанные голоса»: так ролик собирается и видно, сколько не хватило. Счёт — по `usage.jsonl` с отметками сброса; кэш не считается.
- **Отпечаток ролика — stage + то, что ведёт кадр.** Для каждого бита `<stage>+<доминирующее устройство>` (или `+stage`), бит со сценой — `scene:<id>`; совпадение позиций > 60 % с одним из двух последних роликов — ошибка, 40–60 % — предупреждение. Ловит «фото + подпись → цитата → счётчик» подряд, которое кортеж арки не видит. На всех роликах: Great Fire × Halifax — 14 %; выше 60 % только старые Помпеи × Titanic v1 (67 %), который уходит в history.
- **Переходы из реестра — свои canvas-модули по их идее, компоненты вендорены образцом.** В движке переход — оверлей над стыком на общем canvas; компоненты реестра (iris-reveal, directional-wipe, grid-pixelate-wipe, grade-split-reveal) — вставки со слотами A/B, а после стыка уходящего бита уже нет в кадре. grade-split-reveal и блок ridged-burn держатся на шейдере — их аналоги без WebGL; blinds в реестре нет.
- **Ширина кинетического текста — оценкой, а не замером.** Замер canvas при монтировании зависит от того, успел ли загрузиться шрифт: рендер (шрифты встроены) и снимок композиции раскладывали строку по-разному. Оценка по классам символов (em Inter и Cormorant) детерминирована; запас 3–8 % держит строку в области. Субтитры по-прежнему меряют строки canvas — полоса субтитров в сравнение со снимком не входит.
- **Слова кинетики — на словах голоса (`wordsAt`).** Шаг `step` не попадает в слова реплики, а по правилу движка всё привязано к словам: тип параметра `ats` раскладывает список слов в секунды после `at`, как `at`-параметры устройств.
- **Первый не-документальный мир — look `bright-explainer`:** светлая бумага через `palette.colors` (night — лист, text — тушь), семейство субтитров explainer, `typography.kinetic: true`. Тени и подложки текста берут `night`, поэтому на светлом look они сами становятся светлыми ореолами.

- **Хроника British Pathé — риск Content ID.** Pathé регистрирует свой архив в Content ID и на материалы в общественном достоянии; водяной знак — прямой повод для заявки. titanic-v2 кадрирован `crop` (85 % кадра от левого края) — логотип за кадром, но плёнка та же, риск заявки остаётся. ## 14.09.2026, день — D4 «визуальный язык: stage + devices + intent»

- **Бит v2 = stage + 0–3 устройства, сцены с HTML остаются рецептами.** Бит — либо `scene`, либо `stage`; семь сцен Помпей не тронуты (сборка Помпей без рендера после всех правок — все артефакты build/ побайтно как у эталона). Новых HTML-сцен нет: смысл кадра выражается комбинацией stage и устройств.
- **Stage-бит — одна подкомпозиция, которую пишет движок (`engine/src/stage.ts`), без варпа.** Все времена — реальные секунды слов текущего голоса: варп нужен был, чтобы переносить авторскую шкалу сцены Помпей, а у stage-бита авторской шкалы нет. Разметка stage (клипы видео, стоп-кадры, пути карты) статичная, анимации — `HygenStage.mount` и `HygenDevices.mount` на одном paused-таймлайне; видео внутри подкомпозиции HyperFrames находит и сдвигает сам.
- **Устройство — модуль `define(type, mount)` + `device.json`, слои z фиксированы (stage → focus → data → annotate → text).** Модули собираются в `assets/hygen/devices.js`, отдельный файл от `runtime.js` motion: повторная загрузка в шаблоне кадра не должна сбрасывать состояние камеры.
- **Видео — полноценное медиа через подготовку при сборке.** `in`/`out`, reverse и treatment запекаются ffmpeg в H.264 в кэш по хэшу; в рендере — `data-media-start`, `data-playback-rate`; стоп-кадр — точный кадр ffmpeg как `<img>`-клип между двумя видеоклипами, источник продолжается с того же кадра. `fit: contain` — полоса на размытом фоне из того же кадра (архивное 4:3 в 9:16 без апскейла ×5).
- **Обработки media-use (film-memory, engraved, two-ink) — CPU-версии, не шейдерные payload'ы.** Картинки — numpy (штриховка, растры 15°/75°), видео — тоновые карты ffmpeg; движение film-memory (gate weave, дыхание экспозиции) — твинами. Шейдерный путь HyperFrames тянет WebGL и рендер в 1 поток.
- **Компоненты реестра вендорятся и портируются, а не вставляются.** hw-* пишут boil и squash через `tl.eventCallback("onUpdate")` — застывают при перемотке (TRAPS.md). Исходники и sha256 — `engine/devices/vendor/` и `VENDOR.md`; порт живёт в `device.js` на токенах look и шрифтах стиля (Caveat не вендорен).
- **Intent и JSON-рецепт — одна таблица подстановок.** `$target`, `$at±s`, `$data.key|default`, условное устройство `"if"`; явные поля бита побеждают. Резолвер детерминирован по построению (чистая функция video.json и таблиц), проверяется двумя развёртками в одном запуске и хэшем входа против прошлой сборки (`beats.expanded.json`, проверка `expanded` в verify).
- **Координаты устройств — проценты кадра, моменты — слова.** Параметр типа `at` (например, `fillAt` у annotate.box) тоже слово: секунды внутри устройства пришлось бы подбирать под каждый голос.
- **Камера stage-бита двигается только с reason** (approach → push-in, reveal → pull-out, follow → pan, tension → handheld). Look задаёт камеру сценам; stage-бит без reason стоит — у медиа-доказательства камера не должна плыть без смысла.
- **Уникальность скелета — против двух последних роликов по времени сборки,** цвет и текстуры D3.5 — против всех. Пересказ в том же мире объявляется `"retells": "<id>"` и освобождается от проверки цвета только в паре с оригиналом; арка и последовательность stage проверяются всегда.
- **Грамматика — в build до голоса и в verify.** Ошибки останавливают сборку за секунды, а не после 3-минутного рендера; ритм — предупреждения, режиссёр читает их сам.
