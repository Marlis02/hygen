# Решения

Что решили и почему. Новые записи — сверху.

## 13.09.2026

- **Новый движок, а не старый VPE.** Старый строился под побайтовый повтор и гейты, и за месяц на нём не вышло ни одного ролика для выкладки. Новый собирается из ролика про Помпеи: тот вышел пригодным к публикации примерно за 3 часа. Старый репозиторий `/home/ct/Desktop/remotion` — архив, из которого берём модули.
- **Контент на английском, документация на русском.** Канал для англоязычной аудитории.
- **Объём:** 3–5 Shorts в день, каждый через черновик; до 3–4 Long в месяц. Бюджет — Max $100, после монетизации $200.
- **Срок:** одна неделя (13–19.09), MVP к D4. Время фиксировано, объём гибкий.
- **Структура:** репозиторий — папка `hygen`. `engine/` — основной движок, `videos/` — ролики, `examples/pompeii-short` — эталон, только читать.
- **Приёмка без гейтов:** итоговый MP4, кадры, «что видно», автопроверка.
- **Голос:** Kokoro на черновики, ElevenLabs на финалы. Финальные дубли хранятся файлами.
- **Субтитры:** HTML-композиция с пресетами (слово за словом, поп-слова, караоке, минимал), SRT всегда.
- **Звук:** динамику генерируем кодом по таймингам сцен, музыку берём из библиотеки с лицензией.
- **Медиа:** только источники с лицензией, на каждый файл — запись о лицензии.
- **Уникальность роликов:** стиль-пак, одна геройская сцена на ролик, вариации параметров.
- **Docker — позже,** когда рендер переедет на сервер или машин станет несколько.
