# Roadmap — hygen, движок Shorts на HyperFrames

Это единственный план проекта, других копий нет. Раздел «Прогресс» обновляет ревизор после приёмки каждой сессии; сессия читает этот файл первым.

**История плана.** Перед каждой заменой ROADMAP.md старая версия копируется в `roadmap/history/ГГГГ-ММ-ДД_ЧЧММ.md`. Ревизор присылает новый файл как `ROADMAP.new.md` в корень; сессия архивирует старый, переименовывает новый и коммитит.

**Правило: время фиксировано, объём гибкий.** Сессия не укладывается — срезает по порядку срезания своего раздела. Несделанное уходит в долги с адресом.

**Ключевые решения (не пересматривать без причины):** ничего не собирается и не запускается само; регрессии нет, проверка движка — `studio:check`; голос Kokoro по умолчанию, ElevenLabs только «Финалом» с подтверждением; бюджет символов — `voice.budgetChars` в project.json, задаётся обязательным полем в форме брифа при создании (предзаполнение — `voice.defaultBudgetChars` из конфига); режиссёр читает только свой проект, уникальность по `library/index.json`; `claude -p` из панели убран, создание ролика = «Создать» → бриф → диалог `/short <id>`; Agent SDK не используем; без шейдеров/WebGL; **панель переезжает на Preact + Vite в S3 — без права среза; ничего не запускается само (диалог — только по кнопке); панель монохромная.**

## S3 — Редактор (следующая сессия)

Цель: править ролик по времени, глядя на него, а не в JSON. Ничего не собирается само: правка → метка «изменено, пересоберите» → кнопка «Собрать».

- **Блок 0.5 · Создание ролика — починить (не срезается).** Баг 15.09: «Создать» кладёт только `brief.json`, экран проекта требует `project.json` → «нет проекта», а диалог при этом стартует сам и виснет сиротой (лимит 2 исчерпан, «Завершить» недоступна). Исправление: бриф создаёт полный проект-скелет со статусом `brief`; в форме брифа обязательное поле «Бюджет ElevenLabs, символов» (предзаполнено из конфига) → `voice.budgetChars`; «Создать» только пишет файлы и открывает проект — ни диалога, ни исследования, ни поиска медиа, ни сборки, ни превью; всё дальше — по кнопкам; бейдж «идёт диалог» кликабельный с «Завершить»; проверка в `studio:check`.
- **Блок 0.6 · Монохром (не срезается).** Оранжевый акцент убран: белый/серый/графит, цвет только у ошибок и предупреждений, без градиентов и свечений.
- **Блок 0 · Preact + Vite — не срезается.** `studio/web` переезжает на Preact (`preact`, `@preact/signals`) + Vite; сервер `studio/server.ts` остаётся (API + WebSocket + node-pty), Vite в dev как middleware или отдельный порт с прокси, `npm run studio` поднимает всё одной командой; prod-сборка `vite build` → `studio/dist/` (не в git). Все 14 экранов, i18n, живые события → сигналы. Сохраняются достижения S2.1: точечные обновления (ключи в списках), ленивое видео, память фильтров, полоса превью. `studio:check` рендерит форму бита через `preact-render-to-string` вместо `dom-shim`. Готово: 14 экранов без ошибок консоли, `studio:check` 5/5, замер перерисовок за сборку не хуже S2.1.
- **Блок 1 · Карта ролика.** Движок после сборки пишет `build/<id>/timeline.json`: биты (start/end), слова с таймингами, субтитры фразами, устройства (at → секунда, длительность), переходы, музыка (offset, beats), голос (провайдер, кэш). Источник — то, что уже есть в `beats.expanded.json` и таймингах голоса. API `/api/projects/:id/timeline`. Если MP4 не собран — карта строится из проекта без таймингов (оценка длительности по символам) и помечается «оценка».
- **Блок 2 · Дорожки под плеером.** Экран «Редактор» в проекте: плеер MP4 сверху, под ним дорожки — биты, голос (слова), субтитры, устройства, переходы, музыка (сетка битов). Курсор синхронен с плеером; клик по дорожке — seek; зум колесом, прокрутка; выбор бита открывает его форму справа (та же форма, что в «Битах»). Кадр-подсказка при наведении — из контактного листа.
- **Блок 3 · Скраббинг без рендера.** Композиция HyperFrames открывается в iframe панели в режиме паузы; курсор редактора двигает время композиции (`seek`), кадр обновляется без ffmpeg. Сессия сама находит способ: API HyperFrames 0.8.36 для seek, иначе GSAP-таймлайн композиции на паузе. Переключатель «MP4 / композиция». Если композиции нет (проект не собирался) — только MP4/контактный лист.
- **Блок 4 · Перетаскивание.** Три действия, каждое пишет в project.json и ставит «изменено»: (а) граница бита — меняет паузу после реплики (`hold`/пауза бита), реплику не режет; (б) маркер устройства — меняет `at`, снап к ближайшему слову; (в) сдвиг музыки — offset со снапом к сетке битов. Отмена Ctrl+Z в пределах экрана. Устройства и биты не создаются из редактора — только из формы.
- **Блок 5 · Долги.** Журнал диалога — чистый текст (снятие ANSI/перерисовок TUI, или `xterm-addon-serialize` в момент завершения); `history/snapshot.json` пишет машину (hostname + версии whisper/kokoro); правило `behind-subject`: слово не короче фигуры, иначе две строки; навык `/short`: целевая длина реплик с поправкой на провайдер (Kokoro/ElevenLabs — коэффициент из замеров в конфиге).
- **Готово, когда:** панель на Preact + Vite, монохром, 14 экранов, `studio:check` 5/5; «Создать» открывает проект без ошибки и не запускает диалог сам; у Помпей экран «Редактор» показывает все дорожки синхронно с плеером; скраббинг по композиции даёт кадр без рендера; перетаскивание границы, устройства и музыки меняет project.json и панель показывает «изменено»; ничего не собралось само; один коммит, отчёт в `sessions/`.
- **Порядок срезания:** блок 5 → музыка и переходы в дорожках и перетаскивании → отмена Ctrl+Z → скраббинг по композиции (оставить MP4 + контактный лист) → перетаскивание границ (оставить снап устройств к словам). **Не срезаются:** блоки 0, 0.5, 0.6, карта ролика, дорожки битов/слов/субтитров/устройств с seek.
