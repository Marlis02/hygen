# hygen — движок faceless-канала

Движок англоязычного faceless-канала: тема → сценарий → голос → сцены с эффектами → субтитры и звук → черновик → финал. В основном Shorts (1080×1920), позже Long (1920×1080).

- **Документация, отчёты и общение — на русском. Контент роликов — на английском.**
- План и сроки: [ROADMAP.md](ROADMAP.md) — единственный план; перед заменой старая версия уходит в `roadmap/history/ГГГГ-ММ-ДД_ЧЧММ.md`.
- Ловушки рендера: [TRAPS.md](TRAPS.md). Принятые решения: [DECISIONS.md](DECISIONS.md).
- Где сейчас текущая сессия: [PROGRESS.md](PROGRESS.md). Отчёт прошлой сессии — последний файл в [sessions/](sessions/); что старше недели — в `sessions/archive/`. Новая сессия читает **только последний отчёт**.

## Структура

| Папка | Что |
|---|---|
| `engine/` | только код движка: CLI и конвейер (`src/`), шаги на Python (`py/`), рантайм stage (`stage/`), копии скриптов навыков (`vendor/`) |
| `projects/` | ролики: `projects/<id>/` — project.json, media.json, media/, voice/, renders/, history/, dialogs/; proof-проекты с `"proof": true`; рендеры и кэши не в git |
| `library/` | всё, из чего собирается ролик: looks, styles, textures, devices, captions (пресеты и families.json), transitions, motion, scenes (HTML- и JSON-рецепты, CONTRACT.md), arcs, intents, assets (шрифты, карты, GSAP), music; превью `previews/`, голоса `voices/`, отпечатки роликов `index.json` |
| `studio/` | панель `npm run studio` (http://localhost:5177): сервер и API (`server.ts`, `api.ts`), страница Preact + Vite (`web/src`, Vite — middleware того же сервера), диалог с режиссёром, живой канал, редактор, строки `i18n/ru.json` и `i18n/en.json` |
| `examples/pompeii-short/` | исходный ролик про Помпеи, из которого вырос движок — **только читать и копировать, не менять** |
| `sessions/` | архив отчётов сессий |
| `.agents/skills/` | навыки HyperFrames |

## Правила работы

1. **Каждый день заканчивается видео.** Сначала ролик, потом система.
2. **Приёмка — по итоговому MP4.** Нужны контактный лист кадров из MP4, одна фраза «что видно» и автопроверка: пустые сцены, застывшие значения, громкость. Без гейтов, побитовых сравнений и серий одинаковых рендеров.
3. **Время фиксировано, объём гибкий.** Если не успеваем, режем объём по правилам срезания из ROADMAP.md. Дни не добавляются.
4. **Всё привязано к словам голоса, а не к секундам.** Когда меняется голос, сцены и субтитры сдвигаются вместе с таймингами.
5. **Случайность только от сида.** Никаких `Math.random()` без сида и `Date.now()`.
6. **Сначала переделывать готовое:** `examples/pompeii-short` и модули старого репозитория `/home/ct/Desktop/remotion` (его только читать). С нуля пишем только то, чего нет.
7. **Не больше 2 агентов одновременно** — лимит тарифа Max $100.
8. **Каждая проблема рендера — одна строка в TRAPS.md.** Каждое заметное решение — пара строк в DECISIONS.md. Больше документации не нужно.
9. **Автономно.** Команды выполняет агент, ошибки чинит сам. У пользователя спрашиваем только ключи и решения из раздела «Что нужно от пользователя» в ROADMAP.md. Режиссёр в живом диалоге может задать до трёх уточняющих вопросов по ролику.
10. **Прогресс сессии — в `PROGRESS.md`** по правилам раздела ниже. Итог сессии: что сделано, какими командами запускать, сколько заняло, что срезано.
11. **ROADMAP.md — единственный план; перед заменой старая версия уходит в `roadmap/history/ГГГГ-ММ-ДД_ЧЧММ.md`.** Новый план приходит как `ROADMAP.new.md`: сессия архивирует старый, переименовывает новый и коммитит.
12. **Проверка движка — `npm run studio:check`.** Сессия по движку или библиотеке заканчивается зелёными `npm run library:previews` и `npm run studio:check`. Приёмка ролика — по кадрам из его MP4 (правило 2). Регрессии в репозитории нет.
13. **Чистая пересборка = чистое дерево.** Сборка неизменённого ролика ничего не переписывает: контактный лист и обложка без даты и метаданных времени и не перезаписываются, если совпали попиксельно; `publish/` — только при изменении содержимого; строка `library/index.json` — только при изменении отпечатка; снимок в `history/` — только если изменился вход (project.json, media.json, файлы `media/`, дубли `voice/` или коммит движка). Две сборки подряд оставляют `git status` пустым.
14. **Ничего не собирается само.** Ни проекты, ни proof: сборку запускает человек кнопкой или командой. Единственная автоматическая сборка — превью библиотеки.
15. **Голос: черновик — Kokoro, финал — ElevenLabs.** Провайдер по умолчанию всегда Kokoro; `/short`, «Собрать», «Без рендера» и правки битов бесплатны. Финал — кнопка «Финал на ElevenLabs» в шапке проекта: бюджет ролика (`project.json → voice.budgetChars`, умолчание — `voice.defaultBudgetChars`), подтверждение с числом реплик, символов и ожидаемой длительностью. Расход считается по `projects/<id>/voice/usage.jsonl`.
16. **Режиссёр работает в своей папке.** Пишет только в `projects/<id>/` своего ролика, чужие проекты не читает; библиотеку, `CONTRACT.md`, `CLAUDE.md`, README и документы движка читает свободно. Уникальность — `library/index.json`, примеры битов — `library/scenes/CONTRACT.md`.
17. **Редактор и панель ничего не делают сами.** Ни сборки, ни рендера, ни диалога, ни поиска медиа, ни исследования — только по кнопке пользователя («Собрать», «Открыть диалог», «Найти», «Финал»); единственное исключение — превью библиотеки при открытии галереи. «Создать» в «Новом ролике» только пишет бриф и скелет проекта (статус `brief`). Правки редактора (граница бита → `pad[1]`, устройство → `at` со снапом к слову, музыка → `music.in`) идут только через API бита и проекта и ставят метку «изменено, пересоберите»; устройства и биты создаются и удаляются только формой.

## Прогресс сессии

Пользователь следит за сессией по файлу `PROGRESS.md` в корне. Файл всегда показывает, где сейчас работа.

1. **В начале сессии** создать `PROGRESS.md` по шаблону ниже: цель, лимит времени, план шагов. Если от прошлой сессии остался `PROGRESS.md`, сначала прочитать его как контекст, затем перенести в `sessions/` с пометкой `_прервана`.
2. **Во время работы** обновлять файл после каждого завершённого шага и при любой смене статуса: блокер, смена плана, перенос шага. Строка «Сейчас» всегда описывает текущее действие. Время местное, из `date +%H:%M`.
3. **В конце сессии** (или при остановке по лимиту времени) заполнить «Итог» (коротко, 2–3 КБ), поставить статус и перенести файл в `sessions/ГГГГ-ММ-ДД_ЧЧММ_День.md`; отчёты старше недели уходят в `sessions/archive/`. Роликов и MP4 в `sessions/` нет. Время в имени — начало сессии, например `sessions/2026-09-13_1710_D1.md`. Закоммитить вместе с работой. Следующая сессия начинает новый `PROGRESS.md`.

Статусы: «в работе», «остановлена по лимиту», «завершена», «прервана».

Шаблон:

```markdown
# Сессия D1, часть 1 — каркас движка
Начало: 2026-09-13 17:10 · Лимит: 1 час · Статус: в работе

## Сейчас
Собираю CLI: команда build прогоняет конвейер Помпей.

## План
- [x] git init и первый коммит
- [ ] CLI build и doctor ← сейчас
- [ ] автопроверка MP4
- [ ] коммит и итог

## Сделано
- 17:18 — git init, первый коммит; рендеры и node_modules не попали

## Проблемы
- Что сломалось и как решено. Ловушки рендера — ещё и строкой в TRAPS.md.

## Дальше
Что делать следующим, если сессия прервётся.

## Итог
Заполняется в конце: что работает, команды запуска, сколько заняло, что срезано, что осталось.
```

## HyperFrames

- Версия 0.8.36 закреплена. Перед работой со сценами загрузить навыки `/hyperframes`, `/hyperframes-animation`, `/hyperframes-audio`, `/media-use`.
- Сцена — это подкомпозиция (`data-composition-src`) с одним paused-таймлайном в `window.__timelines`.
- Скрипты навыков, на которых держится конвейер, лежат копией в `engine/`, чтобы движок не зависел от установленных навыков.
- Шрифты и GSAP лежат в проекте, не на CDN.
- `npx hyperframes lint` и `npx hyperframes check` обязательны, но последнее слово за кадрами из MP4 (см. TRAPS.md).
- Studio: `npx hyperframes preview --background`, после просмотра `npx hyperframes preview --stop`. Studio дописывает `data-hf-id` в HTML — такие атрибуты в движок не переносить.

## Голос и субтитры

- Черновик озвучивает Kokoro (`npx hyperframes tts`) — всегда и бесплатно. Финал — ElevenLabs по кнопке панели, в бюджете ролика; дубли хранятся файлами в `projects/<id>/voice/` и не перегенерируются. «Обратно на Kokoro» возвращает правки на бесплатный голос, дубли остаются.
- Субтитры — HTML-композиция со стилем-пресетом; SRT экспортируется всегда.
- Безопасная зона Shorts: снизу не меньше 250 px, справа свободно x > 960 на высоте 1000–1700 px.

## Звук

- Звуки под динамику движок генерирует сам, кодом, по таймингам сцен: удары, тики счётчиков, нарастания, свисты, гул, текстуры.
- Музыка берётся из библиотеки `library/music/` с лицензией (music.json), 10–20 треков на стиль; в project.json — только ссылка на трек.
- Голос, музыка и звуки — на отдельных шинах. Музыка и звуки приглушаются под голос. Мастеринг до −14 LUFS, пики не выше −1,5 dBTP.

## Медиа

Только источники с лицензией: Pexels, Pixabay, Wikimedia Commons, NASA. На каждый файл — запись в `projects/<id>/media.json` (ключ — имя файла): источник, автор, лицензия, ссылка, роль. В `media/` — только файлы. Картинки из обычного поиска не брать.

## Секреты и перенос между компьютерами

- Ключи хранятся в `.env` (только секреты) и не попадают в git; всё остальное — `hygen.config.json`. Рендеры, кэши и `node_modules` — в `.gitignore`.
- Версии закреплены, `doctor` проверяет окружение. Финал одного ролика рендерится целиком на одной машине.
- Docker нужен только когда рендер переезжает на сервер или машин становится несколько.
