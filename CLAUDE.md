# hygen — движок faceless-канала

Движок англоязычного faceless-канала: тема → сценарий → голос → сцены с эффектами → субтитры и звук → черновик → финал. В основном Shorts (1080×1920), позже Long (1920×1080).

- **Документация, отчёты и общение — на русском. Контент роликов — на английском.**
- План и сроки: [ROADMAP.md](ROADMAP.md) — единственный план; перед заменой старая версия уходит в `roadmap/history/ГГГГ-ММ-ДД_ЧЧММ.md`.
- Ловушки рендера: [TRAPS.md](TRAPS.md). Принятые решения: [DECISIONS.md](DECISIONS.md).
- Где сейчас текущая сессия: [PROGRESS.md](PROGRESS.md). Отчёты прошлых сессий: [sessions/](sessions/).

## Структура

| Папка | Что |
|---|---|
| `engine/` | основной движок: CLI, конвейер, сцены, стили, звук, автопроверка |
| `videos/` | ролики, по подпапке на ролик; рендеры и кэши не в git |
| `examples/pompeii-short/` | эталонный ролик про Помпеи — **только читать и копировать, не менять** |
| `sessions/` | архив отчётов сессий |
| `.agents/skills/` | навыки HyperFrames |

## Правила работы

1. **Каждый день заканчивается видео.** Сначала ролик, потом система.
2. **Приёмка — по итоговому MP4.** Нужны контактный лист кадров из MP4, одна фраза «что видно» и автопроверка: пустые сцены, застывшие значения, громкость. Без гейтов, побитовых сравнений и серий одинаковых рендеров.
3. **Время фиксировано, объём гибкий.** Если не успеваем, режем объём по правилам срезания из ROADMAP.md. Дни не добавляются.
4. **Всё привязано к словам голоса, а не к секундам.** Когда меняется голос, сцены и субтитры сдвигаются вместе с таймингами.
5. **Случайность только от сида.** Никаких `Math.random()` без сида и `Date.now()`.
6. **Сначала переделывать готовое:** `examples/pompeii-short` и модули старого репозитория `/home/ct/Desktop/remotion` (его только читать). С нуля пишем только то, чего нет.
7. **Не больше 2 агентов одновременно** — лимит тарифа Max $100.
8. **Каждая проблема рендера — одна строка в TRAPS.md.** Каждое заметное решение — пара строк в DECISIONS.md. Больше документации не нужно.
9. **Автономно.** Команды выполняет агент, ошибки чинит сам. У пользователя спрашиваем только ключи и решения из раздела «Что нужно от пользователя» в ROADMAP.md.
10. **Прогресс сессии — в `PROGRESS.md`** по правилам раздела ниже. Итог сессии: что сделано, какими командами запускать, сколько заняло, что срезано.
11. **ROADMAP.md — единственный план; перед заменой старая версия уходит в `roadmap/history/ГГГГ-ММ-ДД_ЧЧММ.md`.** Новый план приходит как `ROADMAP.new.md`: сессия архивирует старый, переименовывает новый и коммитит.

## Прогресс сессии

Пользователь следит за сессией по файлу `PROGRESS.md` в корне. Файл всегда показывает, где сейчас работа.

1. **В начале сессии** создать `PROGRESS.md` по шаблону ниже: цель, лимит времени, план шагов. Если от прошлой сессии остался `PROGRESS.md`, сначала прочитать его как контекст, затем перенести в `sessions/` с пометкой `_прервана`.
2. **Во время работы** обновлять файл после каждого завершённого шага и при любой смене статуса: блокер, смена плана, перенос шага. Строка «Сейчас» всегда описывает текущее действие. Время местное, из `date +%H:%M`.
3. **В конце сессии** (или при остановке по лимиту времени) заполнить «Итог», поставить статус и перенести файл в `sessions/ГГГГ-ММ-ДД_ЧЧММ_День.md`. Время в имени — начало сессии, например `sessions/2026-09-13_1710_D1.md`. Закоммитить вместе с работой. Следующая сессия начинает новый `PROGRESS.md`.

Статусы: «в работе», «остановлена по лимиту», «завершена», «прервана».

Шаблон:

```markdown
# Сессия D1, часть 1 — каркас движка
Начало: 2026-09-13 17:10 · Лимит: 1 час · Статус: в работе

## Сейчас
Собираю CLI: команда build прогоняет конвейер Помпей.

## План
- [x] git init и первый коммит
- [ ] CLI build и doctor ← сейчас
- [ ] автопроверка MP4
- [ ] коммит и итог

## Сделано
- 17:18 — git init, первый коммит; рендеры и node_modules не попали

## Проблемы
- Что сломалось и как решено. Ловушки рендера — ещё и строкой в TRAPS.md.

## Дальше
Что делать следующим, если сессия прервётся.

## Итог
Заполняется в конце: что работает, команды запуска, сколько заняло, что срезано, что осталось.
```

## HyperFrames

- Версия 0.8.36 закреплена. Перед работой со сценами загрузить навыки `/hyperframes`, `/hyperframes-animation`, `/hyperframes-audio`, `/media-use`.
- Сцена — это подкомпозиция (`data-composition-src`) с одним paused-таймлайном в `window.__timelines`.
- Скрипты навыков, на которых держится конвейер, лежат копией в `engine/`, чтобы движок не зависел от установленных навыков.
- Шрифты и GSAP лежат в проекте, не на CDN.
- `npx hyperframes lint` и `npx hyperframes check` обязательны, но последнее слово за кадрами из MP4 (см. TRAPS.md).
- Studio: `npx hyperframes preview --background`, после просмотра `npx hyperframes preview --stop`. Studio дописывает `data-hf-id` в HTML — такие атрибуты в движок не переносить.

## Голос и субтитры

- Черновик озвучивает Kokoro (`npx hyperframes tts`), финал — ElevenLabs с кэшем дублей. Финальные дубли хранятся файлами и не перегенерируются.
- Субтитры — HTML-композиция со стилем-пресетом; SRT экспортируется всегда.
- Безопасная зона Shorts: снизу не меньше 250 px, справа свободно x > 960 на высоте 1000–1700 px.

## Звук

- Звуки под динамику движок генерирует сам, кодом, по таймингам сцен: удары, тики счётчиков, нарастания, свисты, гул, текстуры.
- Музыка берётся из библиотеки с лицензией, 10–20 треков на стиль.
- Голос, музыка и звуки — на отдельных шинах. Музыка и звуки приглушаются под голос. Мастеринг до −14 LUFS, пики не выше −1,5 dBTP.

## Медиа

Только источники с лицензией: Pexels, Pixabay, Wikimedia Commons, NASA. На каждый файл заводится запись: источник, автор, лицензия, ссылка. Картинки из обычного поиска не брать.

## Секреты и перенос между компьютерами

- Ключи хранятся в `.env` и не попадают в git. Рендеры, кэши и `node_modules` — в `.gitignore`.
- Версии закреплены, `doctor` проверяет окружение. Финал одного ролика рендерится целиком на одной машине.
- Docker нужен только когда рендер переезжает на сервер или машин становится несколько.
